# Far Cry 6 startup fix

An experimental launcher for Far Cry 6 that silently closes or gets stuck during startup.

1. [Download the ZIP](https://github.com/midhunmonachan/farcry6-startup-compatibility/releases/download/v0.1.0-experimental/fc6-compatibility-v0.1.0-experimental-win-x64.zip).
2. Extract it.
3. Run **FarCry6-Compatibility.exe**.

Requires the game at `C:\Games\FarCry6` and the [matching game files](supported-files.sha256).

Gameplay works on the tested Core Ultra 9 275HX laptop with Windows build 26300.9711. Other builds, save/load and longer sessions are unverified. Original game files stay unchanged.
